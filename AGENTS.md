# dance-club-backend

**Generated:** 2026-09-22 · **Updated:** 2026-09-22

## Purpose
REST API for scheduling practice rooms for MGH, the Myongji University dance club. It replaces a Google Docs process: admins approve signups and create performances and teams. Team leaders and deputies request practice slots for next week, and admins run an automatic room-assignment pass. The Java package is still named `com.example.ToyProject_Board` because the project began as a board toy project. Do not rename it.

## For AI Agents

### Working In This Directory
- A push to `main` deploys to production automatically (see `.github/AGENTS.md`). Work on a branch unless the user says otherwise.
- The app needs `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`, and `JWT_SECRET` (plus `DB_NAME` for docker-compose). `JWT_ACCESS_EXPIRATION` and `JWT_REFRESH_EXPIRATION` have defaults.
- Production uses `spring.jpa.hibernate.ddl-auto: update`. Entity changes change the live schema on deploy, and there are no migration files. Avoid renaming or dropping columns casually.
- Swagger UI at `http://localhost:8080/swagger-ui.html` is the source of truth for the API. `docs/*.md` are snapshots that can drift.
- **Where CLAUDE.md and README are out of date (trust the code):**
  - `login()`/`reissue()` are in `AuthService`, not `UserService`.
  - `JwtAuthenticationFilter` sets no `request` attribute.
  - Controller tests `@Import` three classes: `SecurityConfig`, `JsonAuthenticationEntryPoint`, `JsonAccessDeniedHandler`.
  - The example test method `createSuccess` does not exist. Real test names are Korean.
  - `JWT_SECRET` is also a required env var.

### Testing Requirements
- `./gradlew test` runs against in-memory H2 (`src/test/resources/application.yml`). No MySQL or env vars are needed.
- Single class: `./gradlew test --tests "com.example.ToyProject_Board.domain.post.PostServiceTest"`.

### Common Patterns
- Layout is by feature: `domain/<feature>/{controller,service,repository,dto}` with the entity at the feature root.
- Errors: throw `BusinessException(ErrorCode.X)`. The response body is `{code, message, errors?}`.
- Code comments, Swagger descriptions, and test display names are written in Korean. Keep that style.
